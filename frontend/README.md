# CRM-Splash Frontend

Next.js 14 (App Router) + TypeScript estricto + Tailwind v4 + shadcn/ui.

## Stack

- Next.js 14 con App Router
- TypeScript estricto
- Tailwind CSS v4
- shadcn/ui (componentes Radix)
- React Hook Form + Zod
- TanStack Table
- @dnd-kit (Kanban)
- Recharts
- date-fns
- lucide-react

## Comandos

```bash
pnpm install
pnpm dev        # desarrollo
pnpm tsc        # type check
pnpm lint       # eslint
pnpm build      # build de producción
```

## Estructura

- `src/app` — rutas App Router
- `src/components` — componentes UI
- `src/lib` — api client, hooks, types, utils
- `src/styles` — estilos globales
